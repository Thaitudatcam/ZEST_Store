# Kế hoạch triển khai AuthCard 3D Flip cho ZestStore

## Tổng quan
Thay thế hiệu ứng slide hiện tại (`translateX(-50%)`) trong `AuthPage.jsx` bằng hiệu ứng **lật trang 3D** (page-turn effect) sử dụng CSS `@keyframes` kết hợp `perspective`, `translate3d`, và `rotateY`.

## Files cần chỉnh sửa

### 1. `frontend/src/pages/AuthPage.jsx` (chỉnh sửa chính)

**Cấu trúc mới:**
```
.auth-card (container chính)
├── .auth-forms-area (bên trái, 50% width — chứa cả 2 form, swap bằng AnimatePresence)
│   ├── RegisterForm (hiện khi isSignUp = true)
│   └── LoginForm (hiện khi isSignUp = false)
└── .auth-overlay (bên phải, 50% width — panel noir gradient + CTA)
    └── Nội dung giới thiệu + nút toggle
```

**Logic thay đổi:**
- Thay `active` state bằng `isSignUp` boolean
- **Overlay** (panel phải): Khi `isSignUp = true`, chạy animation **turn-left** (di chuyển sang trái, tạo cảm giác lật trang). Khi `isSignUp = false`, chạy animation **turn-right** (lật ngược lại về vị trí cũ).
- **Forms** (panel trái): Sử dụng `AnimatePresence` + `motion` để fade/slide swap giữa LoginForm và RegisterForm.
- Overlay dùng **CSS keyframes animation** (không dùng motion library cho hiệu ứng lật 3D, vì CSS `@keyframes` với `perspective` + `translate3d` + `rotateY` phức tạp hơn và perform tốt hơn cho transform này).
- Giữ nguyên toàn bộ logic: `login()`, `register()` từ `useAuth()`, validation, error handling, loading state.
- Giữ nguyên routing: `/login` và `/register` đều render `AuthPage`, detect state từ `pathname`.

**Hiệu ứng lật 3D CSS keyframes:**

```css
@keyframes turn-left {
  0%   { transform: translate3d(0, 0, 0) rotateY(0deg); }
  20%  { transform: translate3d(-25%, 0, 0) rotateY(-2deg); }
  50%  { transform: translate3d(-50%, 0, 0) rotateY(-4.5deg); }
  80%  { transform: translate3d(-75%, 0, 0) rotateY(-1.5deg); }
  100% { transform: translate3d(-100%, 0, 0) rotateY(0deg); }
}

@keyframes turn-right {
  0%   { transform: translate3d(-100%, 0, 0) rotateY(0deg); }
  20%  { transform: translate3d(-75%, 0, 0) rotateY(1.5deg); }
  50%  { transform: translate3d(-50%, 0, 0) rotateY(4.5deg); }
  80%  { transform: translate3d(-25%, 0, 0) rotateY(2deg); }
  100% { transform: translate3d(0, 0, 0) rotateY(0deg); }
}
```

- `animation-duration: 860ms`, `animation-timing-function: linear`, `animation-fill-mode: forwards`
- Container: `perspective: 1500px`, `overflow: hidden`
- Overlay: `transform-style: preserve-3d`, `backface-visibility: hidden`, `will-change: transform`

**Responsive (mobile):**
- Dưới `md` (768px): Vô hiệu hóa hiệu ứng 3D, chuyển sang **fade + slide vertical** đơn giản bằng `motion` (AnimatePresence), hoặc stack 2 form theo chiều dọc. Kiểm tra `useReducedMotion()` hook đã có sẵn.

**Accessibility:**
- Khi form bị che bởi overlay → `aria-hidden="true"` + `inert` attribute
- Focus management: sau animation, focus vào form đang hiển thị
